# Content Migration Notes

The working archive contains 19 entries. `content/catalogue.json` records metadata currently available from the conversation. It does not contain the full manuscript text.

## Migration rules

1. Copy each original manuscript exactly as supplied.
2. Keep Portuguese and English in separate files.
3. Do not silently correct spelling, grammar, punctuation or translation.
4. Record unresolved editorial questions in `editorial-queries.md`.
5. Use the stable work ID as the filename prefix.
6. Do not invent missing publication information.
7. Keep images separate from text and record their captions and attribution.

## Suggested file naming

- `content/pt/001-eu-quis-ir-ao-futuro.md`
- `content/en/001-i-wanted-to-go-to-the-future.md`

For bilingual work, both language files share the same work ID.
